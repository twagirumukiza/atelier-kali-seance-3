8.5 FAQ

Mon ping échoue mais curl fonctionne : est-ce grave ? Non. Le pare-feu filtre peut-être l'ICMP ; le service reste joignable.

**Nmap affiche ppp? pour le port 3000 : est-ce une erreur ?** Non. Le nom vient d'une table de ports ; le ? indique une identification incertaine. Retenez : un service répond.

Wireshark n'affiche aucun paquet. Vérifiez l'interface choisie, le filtre de capture et le filtre d'affichage actif.

Gobuster trouve tout : que faire ? Testez un chemin inexistant : si la réponse est identique, ce sont des faux positifs ; excluez la taille.

Puis-je tester le site de mon établissement ? Non, sauf autorisation écrite du responsable. Cadre légal : articles 323-1 et suivants du Code pénal (R1).
